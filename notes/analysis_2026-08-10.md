# Working analysis — 2026-08-10

Summary of design discussions for the personal WAM lab.

## Goals

Own a Cosmos3-Edge WAM experiment repo (`cosmos-edge-lab`), not a clone dump of
upstream recipes. Engine stays external (`cosmos-framework` + `sync_patches.sh`).

## Tracks

1. **Vision SFT** — world / video dynamics on front cam (module-level full FT).  
2. **Action-Policy SFT** — SO-101 6D, front+wrist, WAM-style.  
3. **Baseline** — π0 3-cam on the same stack task (`upna/pi0_stack_white_blue_black_3cam_*`).

## Key conclusions

- Vision Edge recipe = **full SFT of selected gen modules**, not LoRA.  
- LoRA is upstream’s Super default; for ~120 ep on Edge, prefer short full-module
  runs + early stop over mandatory LoRA.  
- Action heads are a different story (new mapping); LoRA is not the first lever.  
- Edit lab files (`configs/`, `scripts/convert_*.py`, `patches/`); sync patches
  into the engine before Action train.
